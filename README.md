## Day 7 project-1
 Personal Profile Website

This is my personal profile website, created as part of my HTML and CSS practice.

The website contains information about me, my skills, my education, and my goals. I also added a contact form so visitors can enter their details and send a message.

 Features:

- Personal introduction
- Skills and education sections
- Profile image
- Navigation link to the contact page or section
- Contact form with name, email, and message fields
- Basic styling using CSS

Technologies Used:

- HTML5
- CSS3

What I Learned:

While building this project, I practised HTML page structure, headings, links, images, tables, forms, labels, and input fields. I also learned how to style a webpage using CSS, including colors, spacing, borders, and text alignment.

Project Status:

This is a beginner practice project. I will continue improving my web development skills by building more projects.
