- CSS3

## Day 14 project-2
IT Support Ticket Dashboard

This project is a simple IT Support Ticket Dashboard built as part of my web development learning journey.

The dashboard represents a basic company support portal where users can view ticket information and fill out a form to report a technical issue.

Features:

- IT Support Portal navigation bar
- Summary cards for total, open, in-progress, and resolved tickets
- Support ticket table with ticket details
- Priority and status labels
- Form to create a support ticket
- Responsive layout for smaller screens

Technologies Used:

- HTML5
- CSS3
- Flexbox
- Media Queries
- Font Awesome icons

What I Learned:

In this project, I practised creating a dashboard layout with HTML and CSS. I learned how to organize ticket information in a table, style status and priority labels, create forms with different input types, and use Flexbox and media queries to adjust the layout for smaller screens.

Project Status:

This is a frontend practice project. The ticket form is currently a visual form and does not save or process tickets because JavaScript and backend functionality have not been added yet.
I plan to improve my skills by learning JavaScript and adding more functionality to future projects.
